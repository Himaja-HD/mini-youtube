# mini-youtube

**Clone the repository**

git clone https://github.com/Himaja-HD/mini-youtube.git

 
**Installation & Setup**

Create a .env file in the backend folder with:

PORT=5000
MONGO_URI=mongodb://localhost:27017/video-player
JWT_SECRET=your_jwt_secret_key
NODE_ENV=development


cd backend
npm install
node server.js


cd frontend
npm install
npm run dev
